Add or remove workers (run in a terminal in the project folder, Docker Desktop open):
Scale to 6 workers: docker compose up --scale worker=6 -d
Scale down to 1: docker compose up --scale worker=1 -d
Stop all workers (jobs wait in the queue): docker compose stop worker
Start them again: docker compose start worker
Without Docker, each extra terminal running python -m app.worker is one more worker.
